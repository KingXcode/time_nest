# 2.2 独立功能页与普通天气

2026-10-18。基于 2.1 的 24 个热门项目与中文资讯继续调整。

## 当前行为

- 每日看板首页只展示天气、项目更新、汇率和资讯入口，不请求任何模块数据。
- 每个功能独立页面，进入后才加载对应模块，返回时保留用户选择；时钟、倒计时与番茄钟不受影响。
- 天气仅展示当地小时气温、体感、天气状况、降雨概率、风速和逐小时预报。气温来自模型预报，不冒充实时观测。
- 已删除出门窗口建议、节假日/调休日历、拼假逻辑及对应数据适配器与测试。旧假期偏好自动忽略。
- 热门仓库分页、默认中文少数派 RSS、可选 HN 英文、各模块缓存/来源/错误状态保留。

## 验证

- Dart 格式检查与 flutter analyze 通过。
- 完整 Flutter 测试 142 项通过；Node 测试 97 项通过。
- 入口零请求（含已保存城市）、每页仅加载自身模块、返回/重进/偏好恢复、加载中离开及重开均有测试。
- 320px、390px、736×320、1280px，以及 320px 两倍文字缩放通过；新文字字体覆盖已核对。
- 2.2.0+5 发布构建与离线资源清单生成通过。
- 云端 Chromium 已验证四入口首页、独立天气页及真实气温刷新、中文少数派 RSS 加载、24 项目分页、独立汇率结果与返回导航；未执行 iPhone Safari 真机验收。

## 边界

Open-Meteo 免费托管 API 限非商用。第三方网络可能暂时不可用；旧数据有缓存标记及获取时间。此验证不等同 iPhone Safari 真机或中国大陆网络验证。
