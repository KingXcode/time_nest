# 2.3 A 股行情验证

## 范围

- 第五个独立页面，保留时钟/倒计时/番茄钟、天气、项目更新、汇率、资讯。
- 六个固定指数：上证、深证、沪深300、创业板、科创50、中证全指。
- 日线/周线/月线，本机保存选择；以收盘走势为主，不保证实时。
- 无付费、密钥、登录；不访问原始行情 API、不提取组件数据、不编造市场强弱评分。

## 数据与嵌入验证（2026-10-18）

先在 TradingView 官方配置器实际渲染 SSE:000001、SZSE:399001 日线，然后测试应用的精确包装方式。

最终使用官方配置器生成的 Advanced Chart iframe 端点。应用源只执行 CSP 固定哈希的本地启动代码，第三方代码仅在指定 TradingView 跨域 iframe 运行。外层/内层沙箱允许脚本及各自来源，但禁止顶层导航；来源链接可由用户打开。保留图表品牌与 by TradingView 署名。

初次不带 allow-same-origin 的嵌套沙箱使提供方图表空白，已放弃。也未采用 data URL。最终架构在桌面云浏览器确认六个指数均有真实蜡烛图和历史坐标，并测试 320px 和约 254px 内嵌宽度（后者对应 320px 应用扣除卡片边距）。历史拖动可用。

上海组件标注盘后资讯，深圳组件显示自己的更新状态。文案据此使用“不保证实时”，不把 5 秒刷新等同于交易所实时授权。

## 兼容性与边界

- iframe 的 load 事件不证明数据有效；不会由此显示“加载成功”。错误、空白、网络阻挡或授权变化时，页面保留重试和官方来源链接。
- 组件由第三方托管，数据可用性/延迟/授权可能变化；应用不宣称涵盖所有中国股票或北交所。
- 本项目继续构建 JavaScript Web 版本。隔离兼容层使用 dart:html，Flutter 的 WASM dry-run 会提示不支持 WASM；这不是该项目 JS 构建错误。
- 修复自定义 Flutter 启动回调未将 engineConfig 传入 initializeEngine 的旧问题，使视图真实挂载到 #app（包含安全区/动态视口布局）；固定 host 及其直接 flutter-view 根元素增加 overflow:clip，防止原生 iframe 聚焦将 overflow:hidden 容器程序化滚动、导致页面顶部偏移。旧浏览器仍有 hidden 回退。

## 技术面说明

- 使用同一 CSP/跨域边界下的官方 Technical Analysis iframe，固定日线 1D，不提取评级或生成动态文字。均线/振荡指标含义与指数并不代表全市场的限制用静态中文说明。
- 官方原始组件实测：上证、深证、沪深300、创业板、中证全指显示中文评级与指标汇总；科创50 显示无数据，因此应用明确标记评级暂缺，不静默替换为其他指数。
- 评级组件未必显示数据日期；页面明确无法确认截至时间，不包装成“今日”解析。无资金流向、市场宽度、新闻或基本面推断。

## 应用实页回归

- 实际应用中切换指数、日/周/月线后根视图位置保持 0；Flutter 自身滚动可正常看到图表、技术面和说明。
- 最终技术面包装在 254px 宽 × 520px 高下实测五个完整仪表、标签和计数可读；提供方小水平滚动条存在，核心内容与署名保留。
- 返回入口后两个 iframe 均卸载，未留下后台行情框架。
- 升级本地已有缓存通过“新版本已就绪 / 立即更新”完成，保留原指数/周期选择。
