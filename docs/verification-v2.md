# 2.0 每日看板验收

2026-10-18，官方 Flutter 3.47.5 / Dart 3.13.4。

本文件保留 2.0 历史验收。当前 2.2 已改为四个独立功能页，移除出门建议与节假日拼假；参见 [2.2 验收](verification-v2.2.md)。

## 本次改动

- 移除旧八类工具、工具文件/图片桥接、二维码相关依赖及专属测试。
- 时钟、倒计时、番茄钟、展示设置和离线壳保留；每日看板入口固定可见。
- 天气、调休拼假、公开仓库 Releases、每日参考汇率和 HN 资讯五个 API 模块。
- 结果卡片、来源和更新时间、缓存/旧数据/失败/空状态、收藏、排序、本地偏好。
- 中文字体覆盖常用 CJK，动态城市/节日名称无需为常用汉字请求外部字体。

## 自动化

- Dart 格式检查、Flutter analyze。
- Flutter 单元与组件测试：136 项，覆盖既有时钟/计时功能和新看板。
- 新增卡片在 320、390、736×320、1280 像素窗口布局检查；320 像素下 2 倍文字缩放；城市搜索过期响应、取消、重开、选择与本地偏好恢复。
- 调休计算覆盖补班 false 覆盖周末、未知年份、年界、未公布下一年度时的 12 月保护、请假预算和实际工作日倒计数。
- 出门窗口逐小时检查当地 7–21 时，回归测试排除跨午夜的连续小时。
- Node 测试：94 项，覆盖接口契约、请求去重、缓存/旧数据、限流、超时、损坏数据、安全链接，以及既有离线/更新/视口逻辑。
- 完整发布构建与离线资源清单生成。

## 真实浏览器及接口

- 云端 Chromium 桌面实际渲染时钟和双列看板。
- 手动搜索 Shanghai，选择上海，成功加载城市当地小时天气、出门窗口、降雨概率和风速。
- 2026 调休日历显示 10 月 10 日补班，拼假结果实际展示；未知年份和不完整年界由自动化覆盖。
- Frankfurter 每日汇率与 30 天曲线实际展示；同币种 USD/USD 接口也实测返回 1 和供应方日期。
- HN 热门列表实际展示英文原文、分数与评论链接。
- 收藏筛选有效，返回时钟正常；重新进入恢复上海，结果标注缓存与原更新时间。
- GitHub 匿名请求先在云端共享 IP 上遇到真实 403 限流，界面正确显示重试等待时间。额度恢复后，最终构建成功展示 flutter/flutter 的最新发布记录；无 Releases 情况由模拟响应测试覆盖。Release 发布记录不等同仓库最新标签或 SDK 稳定版本。

## 边界

- 上述不等同 iPhone Safari 真机、内地网络或长时间功耗测试。
- Open-Meteo 免费托管接口限非商用；商业部署须另行选择合规方案。
- holiday-cn 为社区整理数据，不是政府官方 API。未知安排不用于推算；请假仍需单位批准。
- 汇率是每日参考数据，非实时成交价，不含费用；资讯为英文原文。
- 无账号、无密钥、无后台；公网接口的地域连通性、更新时效与额度取决于各供应方。
