# 此刻 1.0.0 · 实现与验收记录

## 结论与边界

第一版功能已实现，并完成自动化检查、Web 发布构建及桌面 Chrome 验证。**尚未在真实 iPhone 8 Plus 上验收，也未部署到正式 HTTPS 站点；不能宣称已满足长期摆放的功耗、温度和稳定性要求。**

本记录对应 FVM 固定的 Flutter 3.47.5 stable / Dart 3.13.4。浏览器辅助验证环境为 macOS、headless Chrome 155.0.8059.82、本机 localhost 安全上下文。检查日期：2026-10-17。

真实浏览器检查脚本为 [browser_smoke.mjs](<../tool/browser_smoke.mjs>)。每次执行后在 `build/verification/` 生成截图、带执行时间与构建指纹的报告；该目录属于本地构建产物，不提交到 Git。脚本只启动本机临时服务，不代表已经发布到内网或公网。

本次验证构建指纹：`894cf29d032d04a04557224c28a3db9448dc05f93f7d6e22edc90e21eb895a6b`。静态产物约 40.13 MiB（含 CanvasKit 多变体），ZIP 约 13.46 MiB；首次完整离线缓存的体积与耗时不能忽略，需在目标设备上验证。

## 测试覆盖说明

- **时间**：同一快照、两位时分秒和三位毫秒、午夜/正午、完整 24 小时时制映射、星期、月末/年末、闰日与世纪闰年；设备时间前跳/后跳不累加误差。
- **设置**：缺失/损坏 JSON、未知版本、不正确类型、非法时段、亮度范围、往返编解码、隐藏秒后保留毫秒偏好；跨午夜采用 `[start, end)`，起止相同禁用；夜间不比日常更亮。
- **生命周期**：隐藏时停止更新、恢复立即取系统时间、重复恢复不建立多个循环；可见但无输入焦点的 inactive 窗口仍然更新。
- **交互**：首次说明不阻挡时间、关闭引导持久化、明确开始展示后开启常亮偏好、工具栏空闲隐藏、设置打开时保持、Escape 关闭、12/24 小时和秒开关。
- **浏览器能力**：不支持/非安全上下文/请求拒绝/系统释放、请求尚未完成时隐藏/关闭/销毁、恢复时有限重试、全屏失败不影响基本时钟。
- **持久化失败**：设置写入失败不能被无关的引导标记写入或读取成功掩盖；仅成功保存设置后恢复“可保存”状态。
- **离线及更新**：完整预缓存、资源 SHA-256 验证、半途部署不一致拒绝安装、不缓存错误回包；首次安装失败可显式重试；同源不同 scope 隔离；旧标签固定旧资源、无存活标签的旧缓存在后续激活时清理。

自动化中的 Wake Lock/电源释放条件多为模拟，不等于真实手机已经支持。Chrome 的“断网”同样不替代 iOS 系统对存储回收、主屏幕进程和电源管理的验证。

## 复现命令

在项目根目录执行：

```bash
fvm flutter pub get
fvm dart format --output=none --set-exit-if-changed lib test
fvm flutter analyze
fvm flutter test
node --test test_web/*.test.mjs
bash tool/build_web.sh
node tool/browser_smoke.mjs
```

如改变文案或依赖，重新生成必要字体资源并执行构建/浏览器验证。不要把早前报告当作新构建已经通过的证据。
