# 首页布局预览

2.5.1+14 首页布局功能与卡片边界修复。基于 `0fae372`（2.4.3+12），保留 macOS 和 Web 的现有实现。

## 使用

点一下时钟唤出操作栏，在“此刻 / 切换模式”菜单中选择“首页布局”；也可在“展示设置”中点击“首页布局 · 拖拽与缩放”。

- 默认仍使用原时钟外观。进入预览后启用自定义布局，保存后才应用。
- 时间、日期、天气、K 线分别选择、显示/隐藏、拖动、缩放。
- 手机双指捏合；电脑在预览区域滚轮缩放当前选中模块。方向键微调，也可用加减按钮和“坐标与大小”输入百分比。
- 天气模块中“选择城市”复用现有城市搜索；K 线选择币种和周期，复用每日看板偏好与数据源。
- 手机横屏和竖屏分别编辑、同时保存。重置只重置当前方向的布局。切换预览方向不会覆盖另一方向。
- 电脑（桌面 Web 和原生 macOS）始终使用横屏布局，即使窗口高于宽；不根据窗口宽度判断设备类型。
- 保存应用整个布局草稿；关闭、返回、Escape 丢弃本次修改。再次进入从已保存的布局开始。
- 关闭“启用”并保存可恢复原首页。旧展示设置中的日期开关仍生效，编辑日期时会提示。

## 数据与边界

位置及宽高按安全展示画布百分比保存；缩放和移动自动夹在画布内。手机方向按有效页面方向选择，不会因打开设置面板缩小画布而切换。手动旋转后的拖动使用预览局部坐标。

天气与 K 线的可见卡片边框和编辑选框保持一致，不再因内容等比缩放产生不可见的左右留白；两侧均可贴合安全画布边缘。天气内容左对齐，K 线内容保留居中。

首页天气是所选城市当地时间的当前/下一小时预报，不是设备定位。K 线是币安 OHLC 快照，使用现有绘图器，30 秒刷新；天气 10 分钟刷新。数据失败保留已取到的快照并标记旧数据/更新时间。关闭模块、离开首页或应用进入后台后不继续轮询；未完成请求的过期结果会被丢弃，不会写回已销毁页面。已有请求本身未提供独立取消句柄，不调用会误伤共享页面的币种级取消。

## 验证与预览

自动化测试覆盖模型损坏恢复、边界夹取、两套布局持久化，拖动、双指、滚轮、手动旋转、精确输入、取消/重开、方向切换和桌面窄窗口。数据模块覆盖暂停/恢复、过期请求、错误与旧数据；原行情页默认绘图模式保持回归测试。

生成确定性布局截图：

```bash
HOME_LAYOUT_SCREENSHOTS=1 flutter test test/home_layout_visual_test.dart
```

输出位于 `build/home-layout-previews/`。图片使用自动化测试行情/天气，不能当作实时市场数据。它们是 Linux Flutter 渲染结果，不代表真实 iPhone Safari、PWA 或原生 Mac 实机测试。
