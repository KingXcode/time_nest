# 2.1 热门项目与中文资讯验收

2026-10-18，官方 Flutter 3.47.5 / Dart 3.13.4。

## 改动

- 默认 24 个经 GitHub 验证的热门仓库；React / React Native 使用现行 react 组织，ComfyUI 使用 Comfy-Org。
- 关注容量 50；每页 4 个，只请求当前页，每仓库最多返回一条 Release；1 小时缓存、重复请求去重、匿名预算和共享 IP 限流保护保留。
- 旧单仓库默认迁移为新列表；自定义列表、空列表、取消关注及新版明确选择保留。可手动补齐热门项目。
- 默认中文少数派官方 RSS，HN 三种英文频道仍可选。无后端、定时任务、代理、翻译服务或 API Key。
- RSS 仅取标题、官方文章链接和发布日期；不渲染 description HTML、图片或全文。XML 解析错误、DOCTYPE、异常链接/日期、重复项有校验。
- Release 预发布显式标记；Flutter Release 滞后提示及标签入口，不冒充最新稳定 SDK。

## 验证记录

- 偏好迁移、空列表、取消关注、大小写去重和容量限制单元测试。
- 320px 组件测试覆盖 24 仓库分页按需请求、移除、中文资讯无伪造 HN 分数/评论、切换英文频道。
- Node 接口测试覆盖中文 RSS 归一化、安全校验、空/坏数据、缓存与离线旧数据时间保留；DOMParser 的实际解析另由浏览器确认。
- 官方 RSS 已验证 HTTP 200、application/xml、Access-Control-Allow-Origin: *，包含 10 条中文文章；地域网络仍可能不同。
- Dart 格式检查、flutter analyze、144 项 Flutter 测试、99 项 Node 测试和 release 构建执行通过。
- 云端 Chromium 实际显示 24 个关注项目、分页 1–4 / 5–8，按需加载发布记录；默认少数派中文标题、来源、文章相对发布时间和获取时间全部实际展示。浏览器跨域 RSS 读取与 DOMParser 解析已通过。
- 字体沿用已经内置的常用中文 CJK 覆盖，新文案字形已检查，无缺字。

## 边界

少数派是科技、数码与效率生活媒体，并非实时新闻通讯社；显示原文发布时间与读取时间。RSS 暂时不可达时明确显示错误或上次缓存，不伪造中文翻译。仓库名单不是实时星标排名，Release 记录可能是预发布或子组件。
